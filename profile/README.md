# Full Stack Team1

## 블로그 및 콘텐츠 관리 시스템 구축

풀스택 팀 프로젝트의 네 가지 후보 주제 중 추첨으로 선정된 **블로그 및 콘텐츠 관리 시스템(CMS)**을 개발합니다. 사용자가 글을 작성하고 관리하며, 다른 사용자와 댓글로 소통할 수 있는 웹 서비스를 만드는 것이 목표입니다.

## 주요 과업

| 분야 | 수행 내용 |
| --- | --- |
| 콘텐츠 관리 | 글 작성·수정·삭제, 태그·카테고리 관리, 리치 텍스트 에디터 통합 |
| 사용자·댓글 관리 | 사용자 등록·인증, 댓글 작성·신고, 프로필·권한 관리 |
| SEO·성능 최적화 | DB 스키마 최적화, SEO 친화적 URL·메타 태그, 페이지 로딩 속도 개선·캐싱 |

위 내용은 선정된 과제의 개발 목표이며 구현 완료 목록이 아닙니다.

## 함께 개발하는 방법

- **브랜치:** `main → front/backend → 기능 브랜치 → 세부 작업 브랜치` 순서로 나눠 작업합니다.
- **완료 절차:** localhost 확인·문제 수정·검사 후 PR을 올리고, 본인을 제외한 해당 파트 전원을 리뷰어로 지정합니다. 지적 사항 해결과 전원 승인 후 병합하고, 사용이 끝난 작업 브랜치를 정리합니다.
- **변경 기록:** 커밋·PR 제목에 실제 경로를 넣고, 본문에 변경한 파일별 경로와 작업을 한 줄씩 빠짐없이 적습니다.
- **코드 원칙:** 기존 구조와 공통 부품을 먼저 활용하고 필요한 폴더·파일만 만듭니다. 하드코딩을 하지 않으며 공통 토큰·상수를 사용하고 비밀 값은 올리지 않습니다.
